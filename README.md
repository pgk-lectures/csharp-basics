# C#: основы языка

## Первая программа

```csharp
Console.WriteLine("Привет, мир!");
```

`Console.WriteLine` выводит текст и переводит курсор на новую строку. Текст берётся в двойные кавычки.

```csharp
Console.WriteLine("Меня зовут Анна");
Console.WriteLine("Я изучаю C#");
```

Результат:

```text
Меня зовут Анна
Я изучаю C#
```

В конце большинства команд в C# нужна точка с запятой `;`. Это знак: «команда закончилась».

## Комментарии: заметки для человека

Компьютер игнорирует комментарии. Они нужны, чтобы объяснить код себе и другим.

```csharp
// Эта строка выводит приветствие
Console.WriteLine("Привет!");

/*
   Так можно написать
   комментарий на несколько строк.
*/
```

Пишите комментарии там, где цель кода не очевидна. Не надо комментировать каждую простую строку.

## Переменные: коробки с данными

Переменная — это коробка с названием, в которой лежит значение. Например, в коробке `age` лежит возраст человека.

```csharp
int age = 18;
Console.WriteLine(age);
```

Здесь:

- `int` — тип данных: целое число;
- `age` — имя переменной;
- `18` — значение;
- `=` — положить значение в переменную.

### Основные типы

```csharp
string name = "Маша";       // текст
int age = 18;               // целое число
double temperature = 21.5;  // число с дробной частью
bool isStudent = true;      // да/нет: true или false
char grade = 'A';           // один символ, в одинарных кавычках
```

Запомните: `string` пишется в двойных кавычках, `char` — в одинарных.

### Переменную можно изменить

```csharp
int score = 0;
score = 10;
score = score + 5;
Console.WriteLine(score); // 15
```

Строка `score = score + 5` не является равенством из математики. Она означает: «возьми старое значение `score`, прибавь 5 и положи результат обратно в `score`».

Есть короткая запись:

```csharp
score += 5; // то же самое, что score = score + 5
score++;    // увеличить на 1
score--;    // уменьшить на 1
```

## Ввод данных от пользователя

Чтобы спросить что-то у человека, используем `Console.ReadLine()`.

```csharp
Console.Write("Как тебя зовут? ");
string? name = Console.ReadLine();
Console.WriteLine("Привет, " + name + "!");
```

`Console.Write` выводит текст, но не переносит строку. Знак `?` после `string` означает: пользователь теоретически может ничего не ввести.

Другой удобный способ вставить переменную в текст — интерполяция:

```csharp
Console.WriteLine($"Привет, {name}!");
```

### Как прочитать число

Пользователь вводит текст, поэтому его надо превратить в число:

```csharp
Console.Write("Сколько тебе лет? ");
int age = Convert.ToInt32(Console.ReadLine());
Console.WriteLine($"Через год тебе будет {age + 1}.");
```

Пока пользователь вводит корректные числа, этого достаточно. В реальных программах дополнительно проверяют ввод — это будет дальше.

## Операторы: как считать и сравнивать

### Арифметика

```csharp
int a = 10;
int b = 3;

Console.WriteLine(a + b); // 13 — сложение
Console.WriteLine(a - b); // 7  — вычитание
Console.WriteLine(a * b); // 30 — умножение
Console.WriteLine(a / b); // 3  — целочисленное деление
Console.WriteLine(a % b); // 1  — остаток от деления
```

Если нужен результат с дробной частью, используйте `double`:

```csharp
double result = 10.0 / 3;
Console.WriteLine(result); // 3.3333333333333335
```

### Сравнения

Сравнение даёт `true` или `false`.

```csharp
int age = 18;
Console.WriteLine(age >= 18); // true
```

| Запись | Значение |
| --- | --- |
| `==` | равно |
| `!=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

Не путайте `=` (присвоить) и `==` (сравнить).

## Условия: «если — то»

Условие позволяет программе выбрать действие.

```csharp
int age = 17;

if (age >= 18)
{
    Console.WriteLine("Вход разрешён.");
}
else
{
    Console.WriteLine("Вход пока запрещён.");
}
```

Код в фигурных скобках выполнится только в подходящем случае. Отступы нужны для читаемости; сами скобки отмечают границы блока.

### Несколько вариантов: `else if`

```csharp
int score = 78;

if (score >= 90)
{
    Console.WriteLine("Оценка: 5");
}
else if (score >= 70)
{
    Console.WriteLine("Оценка: 4");
}
else if (score >= 50)
{
    Console.WriteLine("Оценка: 3");
}
else
{
    Console.WriteLine("Оценка: 2");
}
```

### Сложные условия

```csharp
bool hasTicket = true;
int age = 20;

if (hasTicket && age >= 18)
{
    Console.WriteLine("Можно войти.");
}
```

- `&&` — И: оба условия должны быть правдой;
- `||` — ИЛИ: достаточно хотя бы одного истинного условия;
- `!` — НЕ: меняет `true` на `false` и наоборот.

## Циклы: повторяем действие

Цикл нужен, когда одну и ту же команду надо выполнить много раз.

### `for`: когда известно число повторений

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine($"Шаг номер {i}");
}
```

Результат — пять строк. Внутри `for` три части:

1. `int i = 1` — начать с 1;
2. `i <= 5` — повторять, пока условие верно;
3. `i++` — после каждого шага увеличить `i` на 1.

### `while`: пока условие верно

```csharp
int password = 0;

while (password != 1234)
{
    Console.Write("Введите пароль: ");
    password = Convert.ToInt32(Console.ReadLine());
}

Console.WriteLine("Пароль верный.");
```

Следите, чтобы внутри `while` что-то могло изменить условие. Иначе получится бесконечный цикл, который можно остановить `Ctrl + C` в терминале.

## Функции: дать куску кода имя

Если действие повторяется или имеет отдельный смысл, сделайте функцию. Функция похожа на кнопку: вы один раз описали, что происходит при нажатии, и потом вызываете по имени.

```csharp
void SayHello()
{
    Console.WriteLine("Привет!");
}

SayHello();
SayHello();
```

### Функция с параметром

```csharp
void Greet(string name)
{
    Console.WriteLine($"Привет, {name}!");
}

Greet("Олег");
Greet("Нина");
```

`name` — параметр: переменная, которую функция получает при вызове.

### Функция, которая возвращает результат

```csharp
int Add(int firstNumber, int secondNumber)
{
    return firstNumber + secondNumber;
}

int sum = Add(4, 7);
Console.WriteLine(sum); // 11
```

`return` возвращает результат туда, откуда функцию вызвали. Тип перед именем функции (`int`) говорит, какой результат вернётся.

## Массив: несколько значений в одной переменной

Массив хранит набор значений одного типа.

```csharp
string[] names = { "Аня", "Борис", "Вика" };

Console.WriteLine(names[0]); // Аня
Console.WriteLine(names[1]); // Борис
```

Нумерация начинается с нуля. У массива из трёх элементов индексы `0`, `1`, `2`.

Перебрать все элементы:

```csharp
foreach (string name in names)
{
    Console.WriteLine(name);
}
```

## Практика: мини-калькулятор

Программа читает два числа и выводит их сумму, разность, произведение и частное.

```csharp
Console.Write("Введите первое число: ");
double first = Convert.ToDouble(Console.ReadLine());

Console.Write("Введите второе число: ");
double second = Convert.ToDouble(Console.ReadLine());

Console.WriteLine($"Сумма: {first + second}");
Console.WriteLine($"Разность: {first - second}");
Console.WriteLine($"Произведение: {first * second}");

if (second != 0)
{
    Console.WriteLine($"Частное: {first / second}");
}
else
{
    Console.WriteLine("На ноль делить нельзя.");
}
```

Здесь есть переменные, ввод, вычисления и условие — уже почти настоящая программа.

## Практика: угадай число

Компьютер загадал число от 1 до 10. Пользователь пытается угадать его, пока не получится.

```csharp
int secretNumber = 7;
int guess = 0;

while (guess != secretNumber)
{
    Console.Write("Угадайте число от 1 до 10: ");
    guess = Convert.ToInt32(Console.ReadLine());

    if (guess < secretNumber)
    {
        Console.WriteLine("Загаданное число больше.");
    }
    else if (guess > secretNumber)
    {
        Console.WriteLine("Загаданное число меньше.");
    }
}

Console.WriteLine("Верно!");
```

Попробуйте улучшить программу: посчитать количество попыток и случайно выбирать число.

## Задания для самостоятельной работы

1. Спросите имя и возраст человека. Выведите: `Привет, Имя! Через 5 лет тебе будет ...`.
2. Попросите число. Выведите, чётное оно или нечётное. Подсказка: `number % 2 == 0`.
3. С помощью `for` выведите таблицу умножения на 7.
4. Напишите функцию `IsAdult`, которая принимает возраст и возвращает `true`, если человеку 18 или больше.
5. Создайте массив из пяти оценок и найдите их сумму с помощью `foreach`.

## Что запомнить

- **Переменная** хранит данные: `int age = 18;`.
- **Условие** выбирает путь: `if (...) { ... } else { ... }`.
- **Цикл** повторяет код: `for`, `while`, `foreach`.
- **Функция** объединяет действие под именем.
- Ошибки — нормальная часть программирования. Читайте сообщение об ошибке: C# обычно указывает файл и номер строки.

Не пытайтесь выучить всё наизусть. Напишите маленькую программу, запустите, поменяйте числа и условия, посмотрите, как меняется результат. Так C# становится понятным быстрее всего.
