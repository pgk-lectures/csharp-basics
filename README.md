# C# 1. Переменные, типы данных и вывод

Программа выполняет команды сверху вниз. В C# команду обычно заканчивают точкой с запятой `;`.

```csharp
Console.WriteLine("Привет, мир!");
```

`Console.WriteLine` выводит текст в консоль и переходит на новую строку. Текст записывается в двойных кавычках.

```csharp
Console.WriteLine("Я изучаю C#");
Console.WriteLine("Это моя первая программа");
```

## Переменные

Переменная — это именованное место для хранения значения. Её удобно представлять как коробку с наклейкой: имя на наклейке показывает, что лежит внутри.

```csharp
int age = 18;
string name = "Анна";
```

В первой строке `int` — тип данных, `age` — имя переменной, а `18` — её значение. Знак `=` здесь означает «сохранить значение справа в переменной слева».

Значение можно использовать в другой команде:

```csharp
int age = 18;
Console.WriteLine(age);
```

Для вывода текста вместе со значением переменной удобно использовать строку с `$`:

```csharp
string name = "Анна";
int age = 18;

Console.WriteLine($"Имя: {name}");
Console.WriteLine($"Возраст: {age}");
```

Выражение в фигурных скобках внутри такой строки заменяется его значением.

## Типы данных

Тип сообщает C#, какие данные хранятся в переменной и что с ними можно делать.

```csharp
string city = "Самара";
int students = 25;
double temperature = 21.5;
bool isOpen = true;
char groupLetter = 'А';
```

| Тип | Хранит | Пример |
| --- | --- | --- |
| `string` | текст | `"Самара"` |
| `int` | целое число | `25` |
| `double` | число с дробной частью | `21.5` |
| `bool` | истину или ложь | `true` / `false` |
| `char` | один символ | `'А'` |

`string` записывают в двойных кавычках. `char` содержит ровно один символ и записывается в одинарных кавычках.

## Изменение значений

Переменную можно использовать для хранения результата вычислений.

```csharp
int score = 0;
score = 10;
score = score + 5;

Console.WriteLine(score);
```

После выполнения этих строк в `score` находится `15`. Запись `score = score + 5` означает: взять старое значение, прибавить 5 и сохранить результат обратно в `score`.

Короткие записи:

```csharp
score += 5;
score++;
score--;
```

`+=` прибавляет указанное число, `++` увеличивает значение на один, `--` уменьшает на один.

## Арифметика

```csharp
int first = 10;
int second = 3;

int sum = first + second;
int difference = first - second;
int product = first * second;
int wholePart = first / second;
int remainder = first % second;
```

| Оператор | Значение | Пример |
| --- | --- | --- |
| `+` | сложение | `10 + 3` равно `13` |
| `-` | вычитание | `10 - 3` равно `7` |
| `*` | умножение | `10 * 3` равно `30` |
| `/` | деление | `10 / 3` равно `3` для `int` |
| `%` | остаток от деления | `10 % 3` равно `1` |

При делении двух `int` дробная часть отбрасывается. Для дробного результата хотя бы одно из чисел должно быть типа `double`:

```csharp
double result = 10.0 / 3;
Console.WriteLine(result);
```

Остаток от деления помогает определить чётность числа:

```csharp
int number = 14;
int remainder = number % 2;
Console.WriteLine(remainder);
```

Для чётного числа остаток равен `0`.

## Пример: стоимость заказа

```csharp
string product = "Наушники";
int price = 2500;
int quantity = 2;
int total = price * quantity;

Console.WriteLine($"Товар: {product}");
Console.WriteLine($"Количество: {quantity}");
Console.WriteLine($"Итого: {total} руб.");
```

В этом примере программа хранит текст и числа, перемножает цену на количество и выводит готовый результат.
